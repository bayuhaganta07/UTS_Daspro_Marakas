# PATHFINDER — Intelligent Route Planner

Program pencarian dan optimasi rute yang dibuat menggunakan bahasa Pascal untuk tugas UTS Dasar Pemrograman.

## Fitur

- Mencari rute terpendek.
- Mencari rute tercepat.
- Mencari rute termurah.
- Menampilkan daftar lokasi dan jalan.
- Menutup dan membuka kembali jalan.
- Menghindari jalan yang ditutup saat mencari rute.

## Teknologi

- Bahasa pemrograman: Pascal
- Compiler: Free Pascal Compiler (FPC)
- Algoritma: Dijkstra
- Antarmuka: Command Line Interface (CLI)

## Cara Menjalankan

Kompilasi program menggunakan:

`fpc Main.pas`

Jalankan program di Windows menggunakan:

`.\Main.exe`

## Status Proyek

Versi awal telah dibuat dan diuji menggunakan data jalan simulasi.

## Batasan

Data lokasi, jarak, waktu, dan biaya masih berupa simulasi. Program belum menggunakan data jalan nyata atau lalu lintas secara langsung.
